Where each piece of DynaMem lives in stretch_ai, and the call chain for one pick-and-place. Print this.

Call chain for “pick up A and place it on B”

python -m stretch.app.run_dynamem
└─ app/run_dynamem.py:main
   ├─ get_parameters("dynav_config.yaml")
   ├─ HomeRobotZmqClient(robot_ip)                       # talks to the robot over ZMQ
   ├─ DynamemTaskExecutor(...)                           # agent/task/dynamem/dynamem_task.py
   │  └─ RobotAgent(...)                                 # agent/robot_agent_dynamem.py
   │     └─ create_obstacle_map()
   │        ├─ encoder   = MaskSiglipEncoder | MaskClipEncoder (cpu)
   │        ├─ detector  = OwlPerception | YoloEPerception (cpu)
   │        ├─ voxel_map = SparseVoxelMap (voxel_dynamem.py)   ← two clouds live here
   │        ├─ space     = SparseVoxelMapNavigationSpace (voxel_map_dynamem.py)
   │        └─ planner   = AStar(space)
   ├─ executor([("rotate_in_place","")])  or  [("read_from_pickle", path)]
   └─ loop:  executor([("pickup", A), ("place", B)])
         ├─ "pickup" → _find(A) → agent.navigate(A) ──┐
         │            → _pickup(A)                    │  navigate() loops execute_action()
         └─ "place"  → _find(B) → agent.navigate(B)   │  ≤10 times; each call: look_around(),
                      → _place(B)                     │  process_text(), run ≤8 waypoints
                                                      └─ process_text(): verify_point → localize_text
                                                          → sample_navigation → planner.plan

Files

FileRoleFunctions to know
app/run_dynamem.py CLI entry. Parses flags, builds executor, runs the E/M prompt loop. main (flags at top; loop at the bottom)
agent/task/dynamem/dynamem_task.py Command interpreter. Turns ("pickup", A) into navigate + pick, with optional human confirmations. Saves the memory pickle after each navigate. DynamemTaskExecutor.__call__, _find, _pickup, _place, compute_tilt
agent/robot_agent_dynamem.py The agent. Owns the models, the voxel map, planner, rerun view. Implements the closed-loop navigate/explore cycle and the two manipulation paths. create_obstacle_map, update, look_around, rotate_in_place, execute_action, process_text, navigate, run_exploration, manipulate, place
mapping/voxel/voxel_dynamem.py The memory. Subclasses the base SparseVoxelMap; adds semantic_memory, the 2D map with a history layer, text localisation, pickle I/O. EQA code from line ~932 on. process_rgbd_images, add, add_to_semantic_memory, get_2d_map, localize_text, localize_with_feature_similarity, localize_with_mllm, find_all_images, verify_point, write_to_pickle, read_from_pickle
utils/voxel.py Generic voxelised point cloud. Holds points, features, rgb, weights, _obs_counts. The point-removal rule lives here. VoxelizedPointcloud.add, clear_points, get_pointcloud, scatter3d
mapping/voxel/voxel_map_dynamem.py Navigation space over the map: picks a standing pose near a target and picks exploration goals from the time-value map. sample_target_point, sample_navigation, sample_exploration, _time_heuristic, sample_frontier
config/dynav_config.yaml All tunables: voxel size, obstacle heights and density, depth range, filters, planner step sizes. top-level keys; motion_planner.frontier; trajectory_*
agent/manipulation/dynamem_manipulation/ OK-Robot style manipulation: sends head-camera images over ZMQ to the AnyGrasp server, converts the returned 6-DoF pose to joint moves via the URDF. Also the local placing heuristic. grasper_utils.capture_and_process_image, pickup, move_to_point, process_image_for_placing, DynamemManipulationWrapper.move_to_pose
llms/prompts/dynamem_visual_grounding_prompt.py System prompt for GPT-4o when --mllm is on. DYNAMEM_VISUAL_GROUNDING_PROMPT
config/dynamem_urdf.py Patches a calibrated robot URDF for the manipulation code. CLI, run once after copying stretch.urdf

Flags → behaviour

FlagEffect in code
-S / --skipskip_confirmations=True: no “Do you want to run navigation/picking/placement?” prompts.
--visual-servo / --vsBuilds a semantic sensor (OWL+SAM on GPU, YOLOE on CPU) and uses GraspObjectOperation instead of the AnyGrasp socket. Placing runs locally with YOLOE.
--mllm / -Mlocalize_text routes to localize_with_mllm: top-3 images → GPT-4o picks one → OWLv2 pinpoints. Detector switches to smaller OWLv2-B; semantic resolution coarsens to 0.1 m.
--cpuCLIP ViT-B/16 + YOLOE-L, 360×270 images, threshold 0.35. Auto-enabled when CUDA is absent.
--input-pathSkip rotate_in_place; load both clouds from the pickle.
--output-pathName under dynamem_log/ for the pickle and per-frame rgb/depth/pose dumps.
--explore-iter NParsed by click but not passed to the executor: the executor's default of 5 is what actually runs.
--server_ipHost of the AnyGrasp ZMQ server (port 5557).
